# Trigo

A personal call archive. The recording foundation captures microphone and selected
application audio into one recoverable stereo master, with canonical metadata and
durable operations in SQLite. Effect-authored contracts connect the native app to
one authenticated product API running locally or in Cloudflare.

Installed-app acceptance remains [#57](https://github.com/apshenichniy/trigo/issues/57).
Production upload, hosted transcription, synchronization and the transcript UI
remain in [the product epic](https://github.com/apshenichniy/trigo/issues/10).

The product name is **Trigo**. Its primary domain is **usetrigo.com**, purchased
on September 5, 2026.
