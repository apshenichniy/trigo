# Trigo

A personal call archive. The foundation provides shared call-document contracts,
a local Worker with fake ASR, and two buildable macOS application shells.
Recording, real transcription and cloud setup are subsequent issues in [the approved epic](https://github.com/apshenichniy/trigo/issues/10).

See [development setup and commands](docs/development/setup.md),
[contract boundaries](packages/contracts/README.md), and
[agent workflow](docs/agents/development-workflow.md).
